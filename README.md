# clawd 🦀

um, hi. this is clawd, the little orange crab from the claude desktop app, except he lives above your prompt in claude code now. same sprites, just in square pixels

he copies whatever claude is doing. laptop when it's editing, a little monitor when it runs commands, he looks around while it reads stuff, cheers when it answers, and facepalms when something fails. so, mostly facepalming

when he gets bored he wanders off for a bit, crab-walks around, shows off, then goes back to his corner like nothing happened. he has no job and he's thriving

if you also have [agent-grid](https://github.com/v1ol3tr0se/agent-grid) every agent gets its own clawd in its box's color. they wave when they show up, work next to their agent and leave with it when it's done. they *try* not to stand on each other, but with a lot of agents it gets kinda like a train at rush hour, i couldn't fit them all

made with claude code, for claude code.

### you'll need
- claude code 2.1.295 or newer
- a terminal that can draw unicode 16 octants. kitty 0.47+ works, that's what i use

if he shows up as a pile of boxes it's the terminal. he's fine, i checked

### installing
paste this in claude code:

```shell
/plugin install clawd --marketplace v1ol3tr0se/clawd
```

it'll ask to add the marketplace, say `y`, and pick **user** for the scope

nothing to set up after that. give claude something to do and he'll start moving

oh and he hides if there's less than 30 columns or 3 rows of space. he's a bit shy, let him be

if something doesn't work tell me and i'll try to fix it 💜
